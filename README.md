# Boash Gallery

Galeri digital resmi **Boash (Borcess Ashokal Hajar)** — Bogor Center School.

Aplikasi ini menampilkan karya siswa (website, video, desain), informasi sekolah, prestasi, keterampilan, absensi, chat, dan panel admin.

**Tech Stack:**
- Static HTML + CSS + Vanilla JS
- Supabase (Auth Google + Database + Realtime)
- Siap deploy ke GitHub Pages

**Temporary domain:** https://boash.silverhawk.web.id

---

## Struktur Utama
- `index.html` — Gallery karya
- `videos.html` — Galeri video
- `designs.html` — Desain grafis
- `skills.html` — Skills / Kompetensi
- `about.html` — Tentang Boash
- `absensi.html` — Absensi online
- `chat.html` — Chat angkatan
- `admin.html` — Panel Admin
- `profile.html` — Profil pengguna

## Cara Deploy
1. Upload seluruh isi folder ini ke repository GitHub.
2. Aktifkan GitHub Pages (branch `main` / root).
3. Atur custom domain jika diperlukan.
4. Update `data/supabase-config.js` dengan project Supabase milik Boash.
